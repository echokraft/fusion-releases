# Fusion

Fusion is a free generative synth plugin for macOS. This repository hosts public installer downloads only. It does not include source code.

The installer includes:

- Audio Unit (AU)
- VST3
- Standalone app

Mac only for now.

## Download

The latest beta installer is on the [Releases](https://github.com/echokraft/fusion-releases/releases) page.

## Install

1. Download `Fusion-Installer-macOS.pkg`.
2. Open the package and follow the installer prompts.
3. Restart your DAW, or open the standalone app, after installing.

## If macOS blocks the installer

This build is not notarized, so Gatekeeper may warn that it can't be opened because it's from an unidentified developer.

- In Finder, right-click the `.pkg` and choose **Open**, then confirm, or
- Go to **System Settings > Privacy & Security** and choose **Open Anyway**.
